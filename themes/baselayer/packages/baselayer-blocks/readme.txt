Create custom Gutenberg blocks with a field builder.

== Description ==

BaseLayer Blocks lets you define custom blocks in the WordPress admin and use them in the block editor.

== Installation ==

1. Upload the `baselayer-blocks` folder to `/wp-content/plugins/`
2. Activate the plugin through the Plugins screen
3. Open Blocks in the admin menu to create a block
