# Canvas builder (theme kit)

Shared palette + DnD canvas for Forms and Blocks.

Source: `themes/baselayer/src/js/admin/canvas-builder/`  
Built asset: `canvas-builder-admin`  
Enqueue: `bl_canvas_builder_enqueue_kit()` in `includes/canvas-builder.php`

Packages vendor a copy under `assets/vendor/canvas-builder/` for standalone plugin use.

Field cards / layout / conditional logic live in the sibling **form-builder** kit
(`window.BlFormBuilder`).
